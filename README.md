# IMU_Measurement

## 概要

加速度センサをロギングするためのコードです

## 使い方

### マイコン (Arduinoコード)

- 既に書き込みされています。ただし現状の実装では、
    - 使用するIMUの数を修正するとき
    - サンプリングレートを変更するとき (現状は 1660 Hz です)
- など設定を変更するには書き込みし直す必要があります。


- Arduino IDE で書きこみできます。
    - esp32c6 XIAOを使っているので、初めて書きこむ場合は、適宜Arduino IDEのセットアップをしてください
    - https://wiki.seeedstudio.com/ja/xiao_esp32c6_getting_started/


### Python

- 現在は、`python_pyqtgraph_v3.py` でデータを受け取るようになっています。
- 実行する前に、`COM_PORT` をesp32c6 XIAOのポートに修正してください。(デバイスマネージャーで確認可能)
- サンプリングレートも合わせる (1660Hzを使っています)

## その他

- 正弦波の記録が主目的なので、直行検波をして振幅を推定する機能があります。`VIBRATION_FREQ`は推定する正弦波の周波数を指定しています。特に必要ない場合は無視をして、必要に応じて実装を変えてください。
- 現状対応してるセンサはLSM6DS3だけです
